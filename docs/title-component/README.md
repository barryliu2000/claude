# 風格標題元件（title-component）

9:16 風格標題（1080 × 1920）的規格、實作與定稿樣張。

## 檔案

| 檔案 | 用途 |
|---|---|
| `title-component-spec.md` | **規格文件（v3，定稿）**。參數、配色、擠出、投影、各樣式設定、驗收標準。 |
| `extrude.js` | 擠出與投影的實作，參數與規格第 5 節一致。附各樣式的側壁色表。 |
| `title-916-samples.html` | 全部 14 組樣式的示範頁，每組一張卡片（1080 × 1920）。用瀏覽器開啟即可看到。 |
| `final-01.png` | 定稿樣式 01 原配色 |
| `final-02.png` | 定稿樣式 02 反轉 |
| `final-03.png` | 定稿樣式 03 單色奶油 |
| `final-05.png` | 定稿樣式 05 奶油紙雕（白紙字面） |
| `final-07.png` | 定稿樣式 07 金箔 |
| `final-13.png` | 定稿樣式 13 光暈鑲邊（奶油白字面，7 層擠出，無外發光） |
| `final-14.png` | 定稿樣式 14 螢光筆（無擠出，無暈影） |

## 定稿

**定稿為 7 張 PNG**：`final-01`、`final-02`、`final-03`、`final-05`、`final-07`、`final-13`、`final-14`。
這 7 張的參數與 `title-component-spec.md` v3 一致。

`title-916-samples.html` 包含 14 組，其中**只有上面 7 組是定稿**，其餘 7 組（04、06、08、09、10、11、12）是探索稿，未採用。

## 關鍵規則

- 單一平行光，方向 `(0.5, 0.866)`，擠出與投影同方向。
- 擠出 7 層，每層沿光線推進 0.6px。
- 投影為硬邊，6px，`rgba(0,0,0,.28)`。
- **不使用**背景暈影（Halo）與外發光。
- 不含 `.tag`、`.foot` 等小字。

## 已知限制

- 配色為取樣近似值；珊瑚側壁色為中階外推。
- 擠出深度是在縮圖上比較後選定，未逐像素比對參考圖。
